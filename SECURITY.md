# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for a security problem.

Include the steps to reproduce, the affected version (Finder → Get Info on Retext.app, or `CFBundleShortVersionString` in `Info.plist`), your macOS version, and the provider you use with its version (`claude --version`, `codex --version`, or the custom API).

Only the latest release is supported.
