# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers see the report. Don't open a public issue for a security problem. The same form is the private channel for [Code of Conduct](CODE_OF_CONDUCT.md) reports.

Include the steps to reproduce, the affected version (Finder → Get Info on Retext.app, or `CFBundleShortVersionString` in `Info.plist`), your macOS version, and the provider you use with its version (`claude --version`, `codex --version`, or the custom API).

Only the latest release is supported.
